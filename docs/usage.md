# 操作ガイド

## 1. Display を選ぶ

起動すると、接続中の Display が `Displays` に表示されます。Kiosk 再生に使用する Display の「有効」をオンにしてください。

すべて無効の場合は開始できません。新しく接続した Display は無効な状態で一覧へ追加されるため、Kiosk に使用する場合は「有効」をオンにしてください。

Kiosk 起動中に Display を取り外すと対応する Kiosk windowを閉じ、再接続した有効なDisplayにはKiosk windowを再作成します。Display構成や表示領域が変わった場合は、残りのKiosk windowも現在の配置へ追従します。

## 2. Playlist を管理する

`Playlists` の一覧には、保存済みの Playlist が表示されます。

- `+`: Playlist を追加する
- コピーアイコン: 選択中の Playlist を複製する
- ごみ箱アイコン: 選択中の Playlist を削除する
- 上下矢印: Playlist の一覧順を変更する
- `再生対象にする`: Kiosk で再生する Playlist を選ぶ

一覧で選択しただけでは再生対象は変わりません。「現在の再生対象」タグが付いた Playlist が再生されます。Playlist は最低 1 件残るため、最後の 1 件は削除できません。

## 3. Playlist の動作を設定する

選択中の Playlist では次の項目を設定できます。

| 設定               | 内容                                       |
| ------------------ | ------------------------------------------ |
| プレイリスト名     | 一覧に表示する名前                         |
| モニターを分ける   | Display ごとに異なる項目を使用する         |
| ループ再生         | 最後の項目の後で先頭へ戻る                 |
| シャッフル         | 1 周の中で重複しないランダム順にする       |
| 表示時間（秒）     | 画像・Web の既定表示時間                   |
| 読込待機時間（秒） | Web のフォールバックへ切り替えるまでの時間 |

設定は自動保存されます。手動の保存操作はありません。

## 4. 画像・動画・Web を追加する

「プレイリスト項目」の「追加」を押し、種類と入力方法を選びます。

| 種類   | 入力方法           | 補足                               |
| ------ | ------------------ | ---------------------------------- |
| 画像   | ファイルまたは URL | ファイルは複数選択できる           |
| 動画   | ファイルまたは URL | ミュートを設定できる               |
| ウェブ | HTTPS URL          | 読込待機・失敗時の画像を指定できる |

ウェブには、`https://` で始まる有効な absolute URL だけを登録できます。Futa-e は表示先の内容、安全性、権限要求、運用上の適合性を判定しません。表示先の選定と利用は、URL を登録するユーザーの責任で行ってください。

URL で追加した画像・動画・Web は、アプリ独自にはダウンロードしません。通常の表示高速化には Chromium 標準の HTTP cache を使用し、オンラインで取得できない場合は次の項目、Web fallback、または Safe Mode へ移ります。

ファイル選択画面で表示される拡張子は次のとおりです。

- 画像: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.bmp`, `.svg`
- 動画: `.mp4`, `.mov`, `.webm`, `.mkv`, `.avi`

動画の実際の再生可否は、ファイル内の codec と Electron/Chromium の対応状況にも依存します。

選択したローカルファイルはアプリ領域へコピーせず、元の場所から再生します。設定画面や再生画面へabsolute pathは渡さず、アプリ内部の識別子で参照します。ファイルを移動・削除した場合や外付けVolumeを取り外した場合は再生できなくなるため、素材の配置と内容はユーザーが管理してください。

### 表示方法

- `既定秒` / `動画尺`: 画像・Web は Playlist の既定秒数、動画は再生終了時に次へ進む
- `秒数指定`: 指定秒数で次へ進む。動画が先に終了した場合は、その終了時点で次へ進む
- `無期限`: 設定が変わるか再生エラーが起きるまで次へ進まない。動画はループする

追加済みの項目は、鉛筆アイコンで編集し、上下矢印で並び替え、ごみ箱アイコンで削除できます。

## 5. Display ごとに内容を分ける

「モニターを分ける」をオンにすると、Playlist 項目の編集欄が Display ごとのタブへ分かれます。

- メイン Display 名のタブ: メイン Display で使う項目
- その他の Display 名のタブ: その Display だけで使う項目

個別化できるのは Playlist の項目リストです。ループ、シャッフル、既定表示時間、Web 読込待機時間は Playlist 全体で共通です。

## 6. OSログイン時にアプリを起動する

「起動」の「OSログイン時にFuta-eを起動」をオンにすると、macOSへのログイン時にFuta-eを起動します。この設定はpackaged macOS appで利用できます。

ログイン時に起動するのは操作画面とメニューバーだけです。Kiosk再生は自動開始せず、アプリまたはOSの再起動前にKioskを実行していた場合も復元しません。

## 7. Kiosk を開始・終了する

少なくとも 1 台の Display を有効にし、再生対象の Playlist に項目を追加してから、画面上部の「開始」を押します。有効な各 Display に全画面の Kiosk ウィンドウが開きます。

終了方法は次のとおりです。

- `Escape` キーを 2 秒以内に 3 回押す
- macOS メニューバーの Futa E アイコンから「Kioskを停止」を選ぶ

メニューバーでは、Kiosk の開始、操作画面の表示、Futa E の終了も行えます。

## Deep link で操作する

インストール済みの packaged app では、次の deep link を利用できます。

```text
futa-e://kiosk/start
futa-e://kiosk/stop
futa-e://control/show
```

macOS からは、たとえば次のように開けます。

```bash
open 'futa-e://kiosk/start'
```

開発モードでは URL scheme が自動登録されません。

## Safe Mode とフォールバック

- Playlist が空の場合、Safe Mode を表示する
- 画像・動画の読込に失敗した場合、その項目を飛ばす
- すべての項目が再生不能の場合、Safe Mode を表示する
- Web の読込が設定時間を超えた場合、指定したフォールバック画像を表示する
- フォールバック画像が未指定の場合、既定の Safe Mode 画像を表示する

詳細な制約は[既知の制約](./known-limitations.md)を参照してください。
