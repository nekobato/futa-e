# Futa-e Backgrounds

Fullscreen animated web backgrounds for Futa-e Player.

Add any page below as a `Web` asset in Futa-e:

```txt
https://nekobato.github.io/futa-e/stars/
https://nekobato.github.io/futa-e/rain/
https://nekobato.github.io/futa-e/aurora/
https://nekobato.github.io/futa-e/fireflies/
https://nekobato.github.io/futa-e/flow-field/
https://nekobato.github.io/futa-e/constellation/
https://nekobato.github.io/futa-e/particle-waves/
https://nekobato.github.io/futa-e/lifegame/
```

The catalog manifest is available at:

```txt
https://nekobato.github.io/futa-e/backgrounds.json
```
